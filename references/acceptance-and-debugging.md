# 验收与故障定位

区分三层证据：代码静态/数学测试、浏览器实际行为、真实设备性能。只报告本次做过的层。下列浏览器步骤可由人工或当前环境支持的自动化工具执行，技能不强制某个专有浏览器工具。

## 可执行检查

starter：`npm test`、`npm run build`。原案例：`npm run check`、`node scripts/validate-atlas.mjs`、`node scripts/validate-interactions.mjs`、`npm run build`。

技能修改后：

```bash
python3 <SKILL_DIR>/scripts/validate_bundle.py
python3 <SKILL_DIR>/scripts/test_tools.py
```

不要运行 npm audit fix --force 自动跨版本变更。模板依赖固定；确有漏洞时看具体依赖链，在自己的项目中做有范围的更新和回归。

## 浏览器验收表

至少选一个桌面尺寸（例如 1280×800）和一个小屏尺寸（例如 390×844）；如果声称支持完整手机布局，再覆盖 320×568 与 844×390。截图应保留模型和控件，不只截 DOM 文本。

| 步骤 | 动作 | 应观察到 |
|---|---|---|
| 1 | 启动 HTTP 页面 | 模型加载完成，非空画布；无模型解码/shader 错误 |
| 2 | 设为 0% | 完整装配；原模型轮廓与基线一致 |
| 3 | 设为 45% | 类别有规则地散开，部件不缩放、不随机旋转 |
| 4 | 设为 100% | 正视清单、零件有间隔，单指/左键平移 |
| 5 | 100→0 连续往返 10 次 | 回归基准位置，无漂移、无重复对象 |
| 6 | 100% 隐藏一个类别 | 计数减少且剩余重排；隐藏部件点不到 |
| 7 | 搜索一个隐藏类别里的部件并选择 | 目标临时可见、有高亮、有正确详情 |
| 8 | 点击清单中的实体 | 详情 ID 与所点零件一致，不点到原始组装位置 |
| 9 | 拖动并回原点、松手 | 不改变选择；禁止简单 down/up 同坐标判断 |
| 10 | 隔离选择、再退出 | 相机聚焦正确，不被详情挡住；周围集合恢复 |
| 11 | 重置所有 | 0%、默认类别、无选择、默认视角 |
| 12 | 改窗口大小 | canvas/aspect/layout 更新，无水平溢出，底部滑块能操作 |
| 13 | 隐藏全部 | 不出现 NaN/无限距离，能通过开关恢复 |
| 14 | 开启减少动态效果 | starter 直接跳目标，不自动旋转；原版没有此保证 |
| 15 | 离开再进页面/卸载 | 无多个 canvas、无残留 renderer/事件不断累加 |

真正的手机触摸需要实际设备验证，模拟 viewport 只验证尺寸。PointerTap 单元测试覆盖事件判定，不证明真实浏览器事件分发和多指手感。

UI 的几何验收：检查展开后部件是否落在实际可用画布内；计入标题、目录、camera controls、footer、详情和 safe area。AABB 单测不能替代这一步。通用 starter 最终格子在布局平面内分离；透视深度仍可能导致边缘遮挡，必要时改正交相机或增加间距，不把几何压扁冒充修复。

## 故障表：先定位，再修改

| 症状 | 首先检查 | 有范围的修复 |
|---|---|---|
| 页面只有白底 | WebGL 错误、canvas 尺寸、资源 404、启动入口 | 修加载/尺寸/路径；不要先随机加灯 |
| 模型整体黑 | normals、灯、材质、色彩空间 | int16 normal 设置 normalized=true；核对法线 |
| 解压失败或意外 EOF | HTTP 返回码、gzip magic、byte length | 防二次解压；按固定哈希重拉缺失文件 |
| typed array range/alignment 报错 | byte offset、4 字节对齐、indexCount | 修转换器/manifest，不能 catch 后跳过零件 |
| 展开后点不中 | picker.position/matrix 与 shader Δ 是否相同 | 同步 CPU 变换与可见集合 |
| 大量零件飞走或越移越远 | 是否每帧基于上帧 position 加偏移 | 改为 base+offset，重置回精确基准 |
| 45% 抖动/跳跃 | 两个分支在 .45 的端点 | 左右都以同一个 S 连接 |
| 100% 挤成一团 | 是否只用圆心距离、是否把尺寸归一化每个零件 | 按 AABB 尺寸装箱，共同归一整套模型 |
| GLB 某些零件偏两倍 | world transform 烘焙后是否还保留父变换 | 烘焙后根 Mesh 初始变换归零 |
| 隐藏零件仍能选 | Raycaster 候选集合和 fragment visible 是否一致 | 两处使用同一可见函数 |
| 高亮很弱 | Uint8 写的是 1 还是 255 | 写 255；独立 Mesh 不共用可变高亮材质 |
| 移动后突然消失 | CPU frustum 仍用原始合批 bounds | 禁合批 frustum 或正确更新动态 bounds |
| 展开后卡顿 | draw calls、triangles、每帧布局/集合构造、纹理上传 | 按测量合批/缓存/减面，不盲开所有优化 |
| 手机上选中被面板遮住 | 可用画布矩形和实际 DOM 边界 | fit 与 viewOffset 适配真实空间 |
| Three 升级后无展开 | shader chunk replace 是否命中 | 对照新版本 ShaderLib；先退回固定基线验证 |

## 交付记录模板

```text
资产：真实资产/程序示意；来源与许可；parts 数量。
项目：绝对路径；Node/依赖版本；启动 URL。
自动化：命令、退出结果、通过数量。
浏览器：尺寸、实际操作、截图路径、控制台错误。
未覆盖：真机多指、低端 GPU、加载峰值、指定资产或特定格式。
```

不要填没有测量的 FPS、内存值或声称“弱模型百分百复刻”。技能已经提供明确指令与代码，具体模型的执行稳定性仍需独立用例评估。
